# Telegram Bot Setup Guide

Этот гид описывает, как настроить Telegram бота для получения уведомлений о днях рождения на Android и iPhone.

## Требования

- Telegram установлен на устройстве (Android/iPhone)
- Доступ в интернет
- Приложение Birthday Reminder настроено и развернуто

## Шаг 1: Создание Telegram бота

1. Откройте Telegram и найдите бота **@BotFather**
2. Отправьте команду `/newbot`
3. Следуйте инструкциям:
   - Введите имя бота (например: `Birthday Reminder Bot`)
   - Введите юзернейм (должен заканчиваться на `bot`, например: `my_birthday_reminder_bot`)
4. @BotFather предоставит вам **токен доступа** (выглядит как: `123456789:ABCDEfghijklmnOpqrstuvwxyz`)
5. Сохраните этот токен в безопасном месте

## Шаг 2: Получение Webhook URL

Webhook URL для вашего бота:
```
https://ваш-домен.com/api/telegram/webhook
```

Если приложение развернуто на Vercel, замените `ваш-домен.com` на ваш Vercel URL (например: `v0-birthday-reminder-app.vercel.app`)

## Шаг 3: Установка Webhook'а

Замените `YOUR_BOT_TOKEN` на ваш токен и выполните команду:

```bash
curl -X POST "https://api.telegram.org/botYOUR_BOT_TOKEN/setWebhook" \
  -H "Content-Type: application/json" \
  -d '{
    "url": "https://ваш-домен.com/api/telegram/webhook"
  }'
```

Если успешно, получите ответ:
```json
{
  "ok": true,
  "result": true,
  "description": "Webhook was set"
}
```

## Шаг 4: Установка переменной окружения

Добавьте в ваш `.env.local` файл:

```env
TELEGRAM_BOT_TOKEN=YOUR_BOT_TOKEN
```

Например:
```env
TELEGRAM_BOT_TOKEN=123456789:ABCDEfghijklmnOpqrstuvwxyz
```

Если приложение развернуто на Vercel:
1. Перейдите в **Vercel Dashboard** → **Settings** → **Environment Variables**
2. Добавьте:
   - **Name:** `TELEGRAM_BOT_TOKEN`
   - **Value:** Ваш токен
3. Сохраните и пересоберите проект

## Шаг 5: Привязка аккаунта в приложении

### Для Android и iPhone:

1. **Откройте приложение Birthday Reminder**
2. Перейдите в **Настройки** (⚙️)
3. Найдите раздел **Telegram** (внизу в разделе интеграций)
4. Нажмите **"Открыть бота в Telegram"** или откройте вручную: `https://t.me/ваш_bot_username`
5. В чате с ботом отправьте `/start`
6. Бот пришлет вам **код привязки** (6-8 символов)
7. Вернитесь в приложение и введите этот код в поле на странице Telegram
8. Нажмите **"Привязать"**

Если успешно, увидите сообщение "Telegram успешно подключен!"

## Шаг 6: Тестирование уведомлений

1. Вернитесь на страницу Telegram в приложении
2. Нажмите кнопку **"Отправить тестовое сообщение"**
3. В Telegram должно прийти сообщение вида:
   ```
   🔔 Тестовое сообщение
   Это тестовое уведомление из Birthday Reminder
   ```

## Как работают уведомления

Когда наступает время напоминания (в настроенное время):
1. Приложение проверит, есть ли у вас привязанный Telegram
2. Если да — отправит вам сообщение в Telegram:
   - **Если день рождения сегодня:** 🎂 Сегодня день рождения! Иван Петров — исполняется 25 лет!
   - **Если завтра:** 🔔 Завтра день рождения у Иван Петров (исполнится 25 лет)
   - **На другие дни:** 🔔 Через 3 дня день рождения у Иван Петров (исполнится 25 лет)

## Мобильные уведомления

### Android
- Telegram автоматически отправляет push-уведомления на устройство
- Убедитесь, что в **Параметры Telegram** → **Уведомления** включены
- Выберите нужные звуки и вибрацию

### iPhone
- Telegram отправляет APNS-уведомления
- Убедитесь, что в **Параметры iPhone** → **Уведомления** → **Telegram** включены уведомления
- Выберите стиль (Баннер, Звуки, Значки)

## Команды бота

Доступные команды в чате с ботом:

- `/start` — Получить новый код привязки
- `/status` — Проверить статус подключения
- `/help` — Показать справку

## Решение проблем

### "Вебхук не установлен"
- Проверьте, что URL корректен и доступен из интернета
- Убедитесь, что приложение развернуто на Vercel
- Пересоберите приложение после добавления `TELEGRAM_BOT_TOKEN`

### "Код истек"
- Отправьте `/start` еще раз в боте
- Код действует 10 минут

### "Telegram отключен в приложении"
- Проверьте, что вы ввели код правильно
- Отправьте `/status` боту для проверки статуса
- Попробуйте привязать заново

### Уведомления не приходят
- Проверьте, что Telegram привязан (`/status` → должно быть "✅ Ваш аккаунт привязан!")
- Убедитесь, что в приложении указаны корректные дни рождения
- Проверьте, что время уведомления установлено в настройках
- Включите уведомления в Telegram
- Проверьте логи на сервере (Vercel Dashboard)

## Безопасность

- **TELEGRAM_BOT_TOKEN** — приватное значение, никогда не шарьте его
- Код привязки действует только 10 минут
- Привязка использует уникальный ID чата Telegram (chat_id)
- Сообщения отправляются только на привязанный аккаунт

## Поддержка нескольких пользователей

Каждый пользователь приложения может иметь свой собственный Telegram:
1. Каждый привязывает свой аккаунт в приложении
2. Каждый получает свои персональные уведомления
3. Нет совместного доступа — только администратор видит все аккаунты
